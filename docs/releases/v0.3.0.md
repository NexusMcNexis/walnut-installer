# Walnut Installer 0.3.0

The first release: milestones 1 to 3.

## What's in it
- **`walnut-installer`:** the program inside every installer. With a display it shows the walnut-themed screens: Welcome with your art, Folder with a free-space check, Close Steam?, Installing with Cancel (rolled back cleanly), and Done with Launch. Without a display, or with `--text` / `--yes`, it's the text-mode installer.
- **`walnut-installer-text`:** the same installer, text mode only, static (runs on any Linux).
- **`walnut`:** the headless builder, `walnut build project.toml -o my-game-installer` (static).
- **`walnut-builder`:** the WYSIWYG builder: a form, a live preview of every screen, art checks, and Build.
- **Every installer:**
  - adds a menu entry and an optional desktop shortcut;
  - adds the game to Steam with its artwork, closing Steam only after a yes;
  - puts an uninstaller beside the game that removes exactly what was installed.

## Downloads
Each file comes for `x86_64` and `aarch64`; `SHA256SUMS` lists their checksums. The graphical programs need glibc 2.35 or newer (Ubuntu 22.04, Fedora 36, SteamOS 3 and later).
